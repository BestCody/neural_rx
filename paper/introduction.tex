\section{Introduction}
Neural receivers (NRXs) replace channel estimation, equalization, and demapping with a single neural network trained on data~\cite{honkala2021deeprx}. \citet{cammerer2023neural} brought this concept to multi-user multiple-input multiple-output (MU-MIMO) transmission over the 5G NR physical uplink shared channel (PUSCH), using convolutional and graph neural network (CGNN) layers that refine a state per user over several iterations. More iterations yield more reliable log-likelihood ratios (LLRs), but each iteration also adds latency. In the real-time implementation of this NRX, a 1\,ms budget admits two of its eight iterations~\cite{wiesmayr2025realtime}. On our evaluation sequences, the cut to two iterations raises the signal-to-noise ratio (SNR) required for a transport block error rate (TBLER) of 10\% by up to 1\,dB, even when the NRX is retrained for two iterations.

Like other NRXs, this receiver processes each slot independently. Yet the channel of a user evolves continuously, so the pilots of earlier slots carry information about the current channel, which the receiver discards with each slot. Classical receivers exploit the temporal correlation of the channel by filtering pilots across time or by bundling the demodulation reference signals (DMRS) of several slots~\cite{hoeher1997wiener,3gpp38214}. This raises the question of whether an NRX can use the pilots of earlier slots and thus substitute for iterations.

In this work, we propose a stateful NRX that carries channel estimates across slots. It runs two CGNN iterations and keeps, for each user, a pilot memory with the least-squares (LS) channel estimates at the DMRS positions of up to seven previous transport blocks (TBs). A channel filter combines these entries with the LS estimate of the current pilots and provides the result to the first iteration. The weights of this filter are not trained: they are fitted per user by least squares on the memory itself, so the filter requires neither channel statistics nor labels and adapts to the channel of each user. On the current pilots, it measures how many entries still describe the channel and leaves out the others, e.g., after a scheduling gap. We train the NRX on sequences of TBs rather than independent slots, starting from the released weights of the eight-iteration NRX, and add no trained weights. Our results show that, with two iterations, the proposed NRX recovers most of the accuracy that the cut from eight iterations costs.

In summary, our contributions are:
\begin{itemize}
\item We develop a novel stateful NRX that combines a pilot memory of LS channel estimates with a channel filter whose weights are fitted on this memory, without additional trained weights.
\item We evaluate the proposed NRX in simulations of $2\times 4$ MU-MIMO with 16-QAM over sequences of 64 slots, with and without power control. It clearly outperforms the same NRX without the memory, retrained with two iterations on the same data, outperforms stateless NRXs with up to three iterations, performs close to the eight-iteration NRX, and even outperforms it on tapped delay line and urban macrocell channels.
\item The proposed NRX does not increase the number of CGNN weights, and our latency measurements with TensorRT show that it remains real-time capable, whereas the three-iteration NRX exceeds the 1\,ms budget.
\item We show how the network can use the receiver's intermediate results: falling back to a conventional receiver after a cyclic redundancy check (CRC) failure helps for few TBs, whereas with closed-loop power control, most failing TBs can be identified before decoding finishes, so that their retransmissions can be requested early.
\end{itemize}
